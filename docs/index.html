Quick Start

Run Locally in Seconds

git clone https://github.com/SourceCode/refractor-ui-rust.git cd refractor-ui-rust # Launch interactive Optical Glass Task Manager cargo run -p refractor-task-manager # Launch 67-Theme Optical Workbench cargo run -p refractor-workbench # Launch 7-Suite Studio Showcase cargo run -p refractor-studio-showcase # Verify full safety, clippy, and test suite cargo clippy --workspace --all-targets -- -D warnings cargo test --workspace cargo run -p refractor-xtask -- check-repo
Workspace Crates

Modular Cargo Architecture

refractor-security — Zero-dep URL, HTML, OWASP CSV, NaN/Inf, ReDoS-safe highlight & swizzle guards.

refractor-tokens — Pure Rust WCAG 2.2 AA contrast derivation, create_prism_theme & define_theme.

refractor-themes — 5 Optical Glass presets + 62 WebOS-v3 themes across 9 collections.

refractor-core — GPUI ThemeGlobal, concentric SDF optical_surface, OpticalBackdrop, FxOverlay & RefractorApp.

refractor-components — 339 typed RenderOnce GPUI components across 58 categories including horizontal MenuBarTrigger/MenuDropdownItem, WindowTitlebar, and 25 new FX/Shader/Loader components.

refractor-cli & refractor-xtask — Component discovery, swizzling, and ADR/SemVer drift verification.

Desktop Native Polish

Built for Real Desktop Applications

Horizontal Menu System: Top-of-window optical-glass menu bar (File, Edit, View, Theme, Help) with floating dropdown panels, checkmarks, and keyboard shortcuts.

Native OS App Icons: Zero-dependency Windows build.rs Resource ID 1 embedding so GPUI automatically displays your .ico on the taskbar, Alt-Tab, Explorer, and titlebar.

Live Visual FX Studio: Real-time controls for Refraction Intensity, Specular Highlights, Caustic Blooms, Corner Radii, Material Archetypes, and Overlay Intensity.
